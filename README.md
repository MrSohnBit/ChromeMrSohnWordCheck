## 다운로드·설치

1. [GitHub 저장소](https://github.com/MrSohnBit/ChromeMrSohnWordCheck)에서 **Code → Download ZIP**을 클릭합니다.
2. 다운로드한 `ChromeMrSohnWordCheck-main.zip`의 압축을 해제합니다.
3. Chrome 주소창에 `chrome://extensions`를 입력하고 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램 로드**를 클릭하고, `manifest.json`이 들어 있는 `ChromeMrSohnWordCheck-main` 폴더를 선택합니다. ZIP 파일 자체가 아니라 압축 해제한 폴더를 선택하세요.
5. WC 아이콘의 설정에서 [AI Studio](https://aistudio.google.com/apikey)에서 발급한 **본인 API 키**를 저장합니다. 테스트 문장으로 API 호출 1회가 성공해야 저장됩니다.
6. 설정 화면에서 실제 단축키를 확인합니다. 기본값은 Mac **⌘⇧Y**, Windows/Linux **Ctrl+Shift+Y**입니다. 해제됐다면 `chrome://extensions/shortcuts`의 **현재 입력창 오타 교정**에 지정합니다.
7. 관리자 검수 페이지에 버튼이 필요하면 **검수 페이지 교정 버튼 활성화**를 누르고 사이트 권한을 허용합니다.

다른 사람에게는 위 GitHub 저장소 링크를 공유하면 됩니다. 각 사용자는 본인의 API 키를 등록해야 합니다.

설치한 폴더는 삭제·이동하지 마세요. 업데이트할 때는 다시 **Code → Download ZIP**으로 받아 압축을 해제하고, **기존 설치 폴더 안에 새 파일을 덮어쓴 뒤** `chrome://extensions`에서 MrSohnWordCheck의 **새로고침** 버튼을 누르세요. 같은 확장을 다른 폴더에서 중복 등록하지 마세요. 열려 있던 웹페이지는 미저장 내용을 확인한 후 새로고침해 주세요.

## 사용법

- 입력창에 커서를 놓고 단축키를 누릅니다. 일반 입력창에서 부분 선택하면 해당 부분만 검사합니다.
- 왼쪽 원문, 오른쪽 수정문을 비교합니다. **분홍색: 원문 삭제·변경**, **노란색: 수정문 추가·변경**입니다.
- 수정문은 직접 편집할 수 있으며 하이라이트도 갱신됩니다.
- **입력창에 적용**을 누르면 해당 입력칸에 반영됩니다. 취소/Esc는 원문을 유지합니다.
- 변수 `{고객명}`·`[가게명]`, 숫자·연락처·URL·이메일이 달라지면 적용을 차단합니다. 숫자의 표기 변경도 보수적으로 차단합니다.
- **보호할 단어**에 상호명 등을 쉼표로 구분해 입력하면 해당 단어 변경도 차단합니다. 검수 폼의 가게명/상호명 행에서 원문에 포함된 이름을 찾으면 자동 입력하며, 모든 사이트의 상호명을 자동 인식하는 것은 아닙니다. 직접 입력한 단어는 적용 검사에 사용됩니다.
- 적용 후 오른쪽 아래 **되돌리기**로 마지막 적용을 취소할 수 있습니다. 적용 후 입력창이 달라졌으면 되돌리지 않습니다. 새 적용·알림 닫기·페이지 새로고침 시 이전 되돌리기는 종료됩니다.
- 교정 중 원문이 바뀌면 덮어쓰지 않습니다. 자동 메시지 발송·서버 저장은 하지 않습니다.

자동 버튼은 다음 경로에만 표시합니다.

`https://maadm.okpos.co.kr:8090/bizchatRegularCmpnReview/form/<번호>`

- **우리 가게를 소개하는 내용 (1자 이상)**

`tmaadm.okpos.co.kr:8090/bizchatCmpnMessage/form/11`은 일반 단축키 경로로 지원합니다. 버튼 자동 삽입 대상은 아닙니다. 새 사이트에 자동 버튼을 넣으려면 권한·경로·입력칸 식별 코드를 추가해야 합니다.

## 무료 이용과 개인정보

- 모델: `gemini-3.5-flash-lite`. 2026-11-02 [공식 요금표](https://ai.google.dev/gemini-api/docs/pricing)와 실제 호출을 확인한 기록입니다. 향후 변경 시 다시 확인하세요.
- 무료 사용을 원하면 **결제가 활성화되지 않은 무료 프로젝트의 키**를 사용하세요. 확장은 결제 상태를 확인하거나 Google 과금을 차단하지 못합니다.
- 제한 응답은 안내 후 중단하며 자동 재시도·다른 모델 전환은 하지 않습니다.
- 단축키/검사 버튼을 실행하면 해당 교정 텍스트만 Google에 전송합니다. 무료 등급의 데이터 처리 조건은 Google 정책을 확인하세요.
- 키는 Chrome 프로필의 로컬 확장 저장소에 저장합니다. 소스·ZIP에 넣지 않으며 콘텐츠 스크립트에는 읽기 권한을 주지 않습니다. 암호화 금고는 아닙니다.

## 지원 범위와 한계

일반 textarea, text/search/url/tel input, 단순 contenteditable을 지원합니다. 교정 입력은 최대 5,000자입니다. 비밀번호·읽기 전용·iframe 내부·Chrome 내부 페이지·복잡한 서식 편집기는 지원하지 않습니다. Gmail/Notion/Slack 등 모든 서비스 호환을 검증한 것은 아닙니다.

취소는 응답 적용을 막지만 이미 전송된 API 요청 자체가 취소되는 것은 아닙니다. 긴 문장 전체가 바뀐 경우 하이라이트가 넓은 구간으로 표시될 수 있습니다.

## 이 컴퓨터의 폴더 구성 — 중요

현재는 **두 개의 일반 폴더**입니다. 이전에 사용한 심볼릭 링크 방식은 폐기했습니다.

- `MrSohnWordCheck/`: 개발·배포 원본
- `gemini-proofreader/`: 기존 Chrome ID·설정을 보존하기 위한 실행 사본
- `MrSohnWordCheck.zip`: 공유용 최신 배포본
- `gemini-proofreader.zip`: 이전 이름의 호환 압축본, 신규 공유에는 사용하지 않습니다.

개발 원본을 수정하면 실행 사본에도 같은 변경을 반영해야 합니다. 경로와 배포 절차는 [개발 안내](docs/DEVELOPMENT.md)를 보세요.
